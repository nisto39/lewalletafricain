Règles de confidentialité

Dernière mise à jour : 25 septembre 2026.

Ces règles s'appliquent au site Le Wallet Africain et à l'application interne « Content Bot », utilisée pour publier des vidéos sur la chaîne YouTube Le Wallet Africain.

Content Bot utilise les services API YouTube

Content Bot utilise les services API YouTube (YouTube API Services). En utilisant Content Bot, l'utilisateur accepte d'être lié par les Conditions d'utilisation de YouTube. Les données traitées par Google sont soumises aux Règles de confidentialité de Google (http://www.google.com/policies/privacy).

Qui utilise l'application

Content Bot est utilisé uniquement par l'éditeur de la chaîne Le Wallet Africain, pour gérer sa propre chaîne YouTube. Aucun autre utilisateur ne se connecte à l'application.

Données Google utilisées

Avec l'autorisation de l'éditeur, l'application accède à son compte YouTube via l'API YouTube Data (autorisations youtube.upload et youtube.force-ssl) afin de :

  • mettre en ligne les vidéos préparées et validées manuellement ;
  • gérer les métadonnées de ces vidéos (titre, description, sous-titres, miniature) et lire les informations de base de la chaîne.

L'application n'accède à aucune autre donnée Google (e-mails, contacts, fichiers, etc.) et ne collecte aucune donnée concernant d'autres utilisateurs ou chaînes YouTube.

Données stockées

  • Jeton d'autorisation OAuth de l'éditeur, conservé sur un serveur privé, dans un fichier accessible uniquement au compte système de l'application ;
  • identifiants et métadonnées des vidéos de l'éditeur publiées par l'outil (identifiant de vidéo, titre, description, tags, sous-titres, miniature) ;
  • journaux techniques de fonctionnement (dates, identifiants de vidéos, erreurs).

Les données issues de l'API YouTube (y compris celles figurant dans les journaux) sont rafraîchies ou supprimées dans un délai maximal de 30 jours.

Utilisation, partage et sécurité

Ces données servent uniquement à publier et gérer les vidéos de la chaîne de l'éditeur. Elles ne sont ni vendues, ni partagées, ni transférées à des tiers, et ne sont pas utilisées à des fins publicitaires ni pour entraîner des modèles d'IA.

L'utilisation et le transfert par Content Bot des informations reçues des API Google respectent les Règles relatives aux données utilisateur des services API Google, y compris les exigences d'utilisation limitée (Limited Use).

Révoquer l'accès et suppression

L'accès de Content Bot au compte Google peut être révoqué à tout moment :

  • depuis l'outil : la commande Telegram /revoke de Content Bot révoque immédiatement le jeton auprès de Google (via https://oauth2.googleapis.com/revoke) et le supprime du serveur ;
  • depuis la page de sécurité Google : https://security.google.com/settings/security/permissions (également accessible via myaccount.google.com/permissions).

Après une révocation, le jeton et toutes les données API stockées sont supprimés dans un délai de 7 jours.

Visiteurs du site

Ce site n'utilise ni cookies, ni outil de suivi, ni formulaire. Les liens courts /go/… de ce site ne font qu'une redirection vers le site de destination : ils n'enregistrent rien (pas de cookies, pas de suivi, pas de statistiques). Le site de destination applique ses propres règles. Le site est hébergé par GitHub Pages, qui peut conserver des journaux techniques pour la sécurité du service (voir la déclaration de confidentialité de GitHub).
