L'application « Content Bot »

Content Bot utilise les services API YouTube (Uses YouTube API Services)

Content Bot est l'outil interne de la chaîne Le Wallet Africain. Il aide à préparer des vidéos éducatives (rédaction du script, voix, montage) et, après validation manuelle par l'éditeur, à les mettre en ligne sur la chaîne YouTube Le Wallet Africain via l'API YouTube Data (services API YouTube). L'application n'est utilisée que par l'éditeur de la chaîne, pour sa propre chaîne ; elle ne collecte aucune donnée d'autres utilisateurs.
