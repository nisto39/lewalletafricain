Privacy Policy

Last updated: September 25, 2026.

This policy applies to the Le Wallet Africain website and to the internal application “Content Bot”, used to publish videos on the Le Wallet Africain YouTube channel. The French version is available here.

Content Bot uses YouTube API Services

Content Bot uses YouTube API Services. By using Content Bot, users agree to be bound by the YouTube Terms of Service. Data processed by Google is subject to the Google Privacy Policy (http://www.google.com/policies/privacy).

Who uses the application

Content Bot is used only by the owner of the Le Wallet Africain channel, to manage his own YouTube channel. No other user signs in to the application.

Google data accessed

With the owner's authorization, the application accesses his YouTube account through the YouTube Data API (scopes youtube.upload and youtube.force-ssl) in order to:

  • upload videos that were prepared and manually approved;
  • manage the metadata of those videos (title, description, captions, thumbnail) and read basic channel information.

The application does not access any other Google data (emails, contacts, files, etc.) and does not collect any data about other YouTube users or channels.

Data stored

  • the owner's OAuth authorization token, kept on a private server in a file readable only by the application's system account;
  • IDs and metadata of the owner's own videos published by the tool (video ID, title, description, tags, captions, thumbnail);
  • technical logs (timestamps, video IDs, errors).

Data obtained from the YouTube API (including data contained in logs) is refreshed or deleted within 30 days at most.

Use, sharing and security

This data is used only to publish and manage the videos of the owner's channel. It is not sold, shared or transferred to third parties, and it is not used for advertising or to train AI models.

Content Bot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Content Bot's access to the Google account can be revoked at any time:

  • from the tool: Content Bot's Telegram command /revoke immediately revokes the token with Google (via https://oauth2.googleapis.com/revoke) and deletes it from the server;
  • from the Google security settings page: https://security.google.com/settings/security/permissions (also reachable at myaccount.google.com/permissions).

After revocation, the token and all stored API data are deleted within 7 days.

Website visitors

This website uses no cookies, no tracking tools and no forms. The /go/… short links on this website only redirect to the destination website: they record nothing (no cookies, no tracking, no analytics). The destination website applies its own policies. The site is hosted on GitHub Pages, which may keep technical logs for the security of its service (see the GitHub Privacy Statement).
