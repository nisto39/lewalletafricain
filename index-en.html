The “Content Bot” application

Content Bot uses YouTube API Services

Content Bot is the internal tool of the Le Wallet Africain channel. It helps prepare educational videos (script drafting, voice-over, editing) and, after manual approval by the channel owner, uploads them to the Le Wallet Africain YouTube channel through the YouTube Data API (YouTube API Services). The application is used only by the channel owner, for his own channel; it does not collect any data about other users.
